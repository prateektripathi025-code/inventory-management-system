# InventoryPro - C++ + HTML Inventory Management System

A college-friendly Inventory Management System with a professional HTML/CSS/JavaScript dashboard and a separate C++ inventory logic module.

## Features
- Login
- Dashboard with statistics
- Product management
- Inventory / stock tracking
- Sales
- Purchases
- Suppliers
- Categories
- Reports + CSV export
- Settings
- Search and category filter
- Low-stock alerts
- LocalStorage data persistence
- `main.cpp` with Product struct, sellProduct() and purchaseProduct()

## Run the website
1. Extract the ZIP.
2. Open the `InventoryPro_Upgraded_CPP_Web` folder in VS Code.
3. Open `public/index.html`.
4. Right-click it and choose **Open with Live Server**.
5. Login with:
   - Username: `admin`
   - Password: `admin123`

## C++ note
`main.cpp` contains the C++ inventory-management logic. The browser demo is intentionally runnable without a C++ compiler, so the HTML dashboard uses JavaScript for the interactive demo. To execute `main.cpp` itself, use a C++ compiler such as g++.
